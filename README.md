# Quick Jira

Raycast extension for creating Jira issues with AI-generated summaries.

## Setup

1. Install in Raycast
2. Configure preferences:
   - Jira email
   - Jira API token (from https://id.atlassian.com/manage-profile/security/api-tokens)
   - Anthropic API key

## Usage

- Enter description → Claude generates summary → Creates Jira issue
- Manual summary override available
- Issue URL copied to clipboard automatically
